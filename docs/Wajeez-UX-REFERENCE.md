# Wajeez — مرجع UX عربي للمكتبة الشخصية الذكية

الموقع: https://wajeez.com/

يستخدم هذا المرجع للاستلهام في **تنظيم تجربة المستخدم فقط**، وليس لنسخ الهوية أو النصوص أو الرسومات أو التصميم التفصيلي.

## أفكار مفيدة للمشروع
- وضوح المكتبة والرفوف مع ازدياد عدد الكتب.
- إبراز «تابع من حيث توقفت» بدل إجبار المستخدم على البحث عن كتابه النشط.
- الجمع بين القراءة والاستماع في تجربة واحدة.
- عرض التقدم بوضوح.
- تقليل ازدحام الواجهة وإظهار الإجراء التالي بوضوح.
- تصنيف الكتب وحالاتها بحيث تبقى المكتبة قابلة للإدارة عند التوسع.

## ما يميز منصتنا عنها
- المستخدم يرفع كتابه الخاص.
- مسار كتاب كامل: رفع → قراءة → تحليل → ملخص → صوت → أسئلة → تذكير.
- فصل واضح بين المجاني والمدفوع.
- ربط الإجابات بالكتاب نفسه.
- تتبع تكلفة AI لكل كتاب.
- حماية قانونية وخصوصية مرتبطة بكل كتاب.

## قاعدة التصميم
قبل أي تغيير كبير في الشكل العام، تُراجع هذه الوثيقة مع بقية مراجع UX، ويُعتمد فقط ما يحسن التنظيم والوضوح دون تغيير هوية المنصة الأساسية.
