# قالب الاستيراد اليدوي (JSON) — V0.7

هذا القالب مخصص للمرحلة السادسة من الميزان الصفري: تلخيص/ترجمة "بلا تكلفة" داخل
تطبيق المكتبة، عبر لصق نتيجة JSON أنشأتها بنفسك يدويًا (خارج التطبيق) باستخدام
ChatGPT أو Claude أو أي أداة أخرى. **التطبيق نفسه لا يرسل نص الكتاب أو أي جزء
منه إلى أي خدمة خارجية في هذه الخطوة** — أنت من يقوم باللصق والنسخ يدويًا، ثم
يلصق النتيجة هنا فقط ليحفظها التطبيق ويعرضها بوضوح كـ"مستوردة يدويًا".

يتحقق `src/lib/textAnalysis.ts` (`validateManualImport`) من هذا القالب حرفيًا
قبل الحفظ، ويرفض أي حقل ناقص أو من نوع خاطئ مع رسالة خطأ واضحة تحدد كل مشكلة.

## الحقول الإلزامية

| الحقل | النوع | الوصف |
|---|---|---|
| `template_version` | نص | نسخة القالب، مثال: `"manual-v1"` |
| `source` | نص، أحد: `manual_chatgpt` \| `manual_claude` \| `manual_other` | من أنشأ التحليل فعليًا |
| `output_language` | نص، أحد: `ar` \| `en` \| `bilingual` | لغة النص المُدخل |
| `overview.summary` | نص غير فارغ | الخلاصة العامة |

## الحقول الاختيارية

- `overview.key_ideas`: مصفوفة نصوص (الأفكار المحورية)
- `overview.return_to_source`: مصفوفة نصوص (مواضع يُنصح بالعودة إليها في الأصل)
- `chapters`: مصفوفة كائنات، كل عنصر يتطلب `title` و`summary` (نصان غير فارغين)، ويقبل `pages_if_known` اختياريًا
- `critical.strengths` / `critical.limitations` / `critical.platform_inferences`: كل منها مصفوفة نصوص اختيارية

## مثال كامل صالح

```json
{
  "template_version": "manual-v1",
  "source": "manual_chatgpt",
  "output_language": "ar",
  "overview": {
    "summary": "يناقش الكتاب مفهوم إدارة المعرفة وأثره على المؤسسات.",
    "key_ideas": ["المعرفة أصل متجدد", "التقنية وحدها لا تكفي"],
    "return_to_source": ["تعريف المعرفة الضمنية في الفصل الثاني"]
  },
  "chapters": [
    { "title": "من البيانات إلى المعرفة", "summary": "يشرح الفرق بين البيانات والمعلومة والمعرفة.", "pages_if_known": "1-24" }
  ],
  "critical": {
    "strengths": ["أمثلة تطبيقية واضحة"],
    "limitations": ["لا يناقش أدوات الذكاء الاصطناعي الحديثة"],
    "platform_inferences": ["يمكن تعميم الإطار على المكتبات المتخصصة"]
  }
}
```

## أخطاء شائعة تُرفض تلقائيًا

- إرسال مصفوفة أو نص مباشرة بدل كائن جذر (`{...}`) — مرفوض.
- نسيان `overview.summary` أو تركه فارغًا — مرفوض.
- قيمة `source` خارج القائمة الثلاث المسموحة — مرفوضة.
- عنصر في `chapters` بلا `title` أو بلا `summary` — يُرفض العنصر مع تحديد رقمه.

كل الأخطاء تُجمع وتُعرض معًا (وليس أول خطأ فقط)، حتى تصلح القيم كلها من محاولة واحدة.
