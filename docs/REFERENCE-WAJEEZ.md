# مرجع عربي — وجيز (Wajeez)

## الحالة
مرجع عربي معتمد للاستلهام في تجربة المستخدم والمحتوى الصوتي، دون نسخ التصميم أو المحتوى أو الهوية البصرية.

## الرابط الرسمي
- https://wajeez.com/
- التطبيق: https://app.wajeez.com/
- الخصوصية: https://wajeez.com/privacy?lang=ar
- الشروط: https://wajeez.com/tos?lang=ar

## ما يستحق الدراسة والاستفادة
1. تقديم القيمة بسرعة: معرفة مختصرة قابلة للقراءة والاستماع.
2. الجمع بين الملخص النصي والملخص الصوتي داخل تجربة واحدة.
3. التخصيص وفق أهداف واهتمامات المستخدم.
4. دعم الاستخدام عبر الهاتف والحاسوب والجهاز اللوحي.
5. إظهار التقدم والإنجاز بصورة واضحة.
6. دعم الاستخدام دون اتصال عند توفره.
7. جعل الصوت جزءًا أساسيًا من الرحلة وليس ميزة ثانوية.
8. مسارات تعلم/قراءة واضحة بدل عرض المحتوى بصورة مشتتة.
9. وضوح السياسات القانونية والخصوصية وروابطها.

## أفكار مرشحة لمنصتنا
- مسار كتاب مرئي: رفع > نص > تحليل > ملخص > صوت > أسئلة > تذكير > مكتمل.
- بطاقة تقدم لكل كتاب مع حالة: لم يبدأ / جاري / مكتمل / يحتاج تدخل.
- زر متابعة من حيث توقفت للقراءة والاستماع.
- واجهة موحدة للنص والصوت والتحليل والأسئلة.
- توصيات لاحقة مبنية على اهتمامات المستخدم وكتبه، بعد إثبات الحاجة.
- تنزيل/تخزين آمن لبعض المخرجات للاستخدام دون اتصال، وفق حقوق الاستخدام.
- صفحة واضحة للخصوصية وحقوق النشر والمحتوى المولد بالذكاء الاصطناعي.

## حدود الاستفادة
- لا نسخ للنصوص أو الصور أو العلامة التجارية أو التصميم التفصيلي.
- لا نفترض أن كل ميزة ظاهرة في وجيز مناسبة لنا؛ كل فكرة تمر باختبار حاجة وأمان وتكلفة.
- الأولوية لتجربة الكتاب الواحد الحالية قبل أي توسع بصري كبير.

## قرار المشروع
يُستخدم وجيز كمرجع عربي ضمن مراجعات UX/UI والإلهام الوظيفي قبل أي تعديل كبير في الشكل العام للمنصة، إلى جانب المراجع الأخرى المعتمدة.
