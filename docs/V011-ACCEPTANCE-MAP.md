# V0.11 — خريطة قبول تجربة الكتاب الواحد

هذه الخريطة هي المرجع التنفيذي قبل فتح أي استهلاك OpenAI مدفوع.

## 1. قاعدة مستقرة
- الحساب الدائم يعمل على الهاتف والكمبيوتر.
- الكتاب الموجود يظهر دون إعادة رفع.
- لا تُخزن استجابات Supabase في Service Worker cache.
- `VERSION` و`package.json` و`PROJECT-STATUS.md` متطابقة.

## 2. المكتبة القابلة للنمو
- بحث بالعنوان.
- فلاتر: الكل / جديد / أقرأ الآن / جاهز.
- بطاقة كتاب واضحة: العنوان، المؤلف إن توفر، عدد الصفحات، الحالة.
- فتح «مسار الكتاب» من كل بطاقة.

## 3. مسار الكتاب
رفع ✓ → قراءة → تحليل → ملخص → صوت → أسئلة → تذكير.

كل مرحلة تعرض حالة حقيقية فقط: مكتمل أو لم يبدأ، ولا يُعرض نجاح وهمي.

## 4. القراءة
- فتح PDF المحفوظ من Supabase دون اختيار الملف مرة أخرى.
- حفظ الصفحة والإشارات في `spl_reading_progress`.
- العودة إلى آخر صفحة من جهاز/جلسة أخرى بعد تسجيل الدخول.

## 5. التحليل
- التحليل المحلي مجاني ولا يرسل PDF إلى OpenAI.
- التحليل المدفوع منفصل بزر واضح ولا يبدأ تلقائيًا.
- التحليل المدفوع الموجود يُعاد استخدامه بدل دفع التكلفة مرة أخرى.

## 6. الملخص
- ملخص AI محفوظ داخل `spl_analyses`.
- النص مخصص كخلاصة أصلية لا كنسخ حرفي للكتاب.
- النسخة المستهدفة للاستماع نحو 12–18 دقيقة في الـpilot الحالي، وتراجع بعد تجربة الكتاب.

## 7. الصوت
- الصوت الاحترافي من الملخص وليس الكتاب الكامل.
- لا إعادة توليد إذا كانت المقاطع محفوظة.
- اختبار قبول عربي إلزامي: مخارج الحروف، التشكيل/الوقف، أسماء العلم، الأرقام، والكلمات الإنجليزية داخل العربية.
- الاختبار الحقيقي على iPhone + Android/Chrome + كمبيوتر قبل اعتماد المزود/الصوت.

## 8. اسأل الكتاب
- السؤال لا يفتح قبل وجود التحليل المدفوع.
- الإجابة مرتبطة بالكتاب مع مراجع عند توفرها.
- الحدود الخادمية تمنع الاستهلاك المفتوح.

## 9. التنبيهات
### محلي
- طلب إذن الإشعارات.
- زر اختبار Notification حقيقي.
- الضغط على التنبيه يفتح نفس الكتاب عبر `?book=<id>`.

### خلفية Web Push
- Migration `20260827_0004_spl_v011_book_journey.sql`.
- جدول `spl_book_reminders`.
- جدول `spl_push_subscriptions`.
- Service Worker يستقبل `push` و`notificationclick`.
- Edge Function `spl-reminders` ترسل التنبيهات المستحقة.
- لا تُعتبر الميزة «مفعلة» قبل إضافة VAPID secrets وجدولة dispatcher واختبارها على جهاز فعلي.

## 10. بوابة التكلفة
- OpenAI يبقى مقفلاً أثناء البناء والمراجعة.
- Pilot كتاب واحد أولاً.
- إعادة استخدام التحليل والصوت الموجودين بدل إعادة الطلب.
- مراجعة سجل التكلفة لكل كتاب قبل التوسع.
