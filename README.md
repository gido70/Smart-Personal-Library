# المكتبة الشخصية الذكية — V0.3

نموذج تطبيقي عام مهيأ للنشر على GitHub Pages. هذه النسخة تختبر الواجهة وقارئ PDF المحلي؛ التحليل الحقيقي والصوت وقاعدة البيانات مراحل لاحقة موضحة بوضوح داخل التطبيق.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## النشر

يدفع المستودع إلى فرع `main`، ثم ينشر GitHub Actions مجلد `dist` تلقائيًا عبر GitHub Pages.

## الخصوصية الحالية

قارئ الأصل يفتح ملف PDF داخل ذاكرة المتصفح. لا يرفع الملف إلى الخادم. يُحفظ رقم آخر صفحة محليًا فقط.

## المرحلة التالية

ربط Supabase لتجربة حساب المستخدم، فهرسة مكتبته، سجل التقدم، والتنبيهات. لا تُرفع ملفات الكتب إلى التخزين قبل تصميم سياسة الحقوق والاحتفاظ والحذف.
